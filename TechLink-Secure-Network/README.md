# TechLink Solutions — Secure Network Segmentation (Cisco Packet Tracer)

## 🔹 Overview
This project simulates the network of a mid-sized company using VLANs, ACLs, DHCP, DNS, and RIPv2 to enforce segmentation and least-privilege access.

## 🔹 Tasks Performed
- VLANs for HR, IT, Admin  
- Router-on-a-stick configuration  
- RIPv2 dynamic routing  
- DHCP & DNS server setup  
- ACLs for least privilege  
- Full connectivity testing  

## 🔹 Tools Used
- Cisco Packet Tracer  
- Windows/Linux endpoints  
- DNS & DHCP server roles  

## 🔹 Deliverables
- Packet Tracer file (.pkt)  
- Network diagram  
- Configuration files (running-config)  
- Screenshots of connectivity tests
