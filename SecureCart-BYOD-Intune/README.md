# SecureCart — BYOD & Intune Compliance Project

## 🔹 Overview
This project simulates a Bring Your Own Device (BYOD) environment using Microsoft Intune and Entra ID to enforce security policies such as BitLocker encryption, password rules, firewall protection, and Conditional Access.

## 🔹 Tasks Performed
- Device enrollment and compliance evaluation  
- BitLocker encryption enforcement  
- Firewall and antivirus policy configuration  
- Password & security baseline configuration  
- Conditional Access setup: MFA + Compliant Device  
- Testing access restrictions from non-compliant devices  

## 🔹 Tools Used
- Microsoft Intune  
- Microsoft Entra ID (Azure AD)  
- Compliance Policies  
- Configuration Profiles  
- Conditional Access  

## 🔹 Deliverables
- Compliance policy summary  
- Configuration policy screenshots  
- Conditional Access screenshots  
- Device compliance report  
- Enrollment steps
