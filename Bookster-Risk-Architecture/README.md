# Bookster — Security Architecture & Risk Management Project

## 🔹 Overview
This project focuses on building a secure architecture for a fictional company (Bookster), identifying risks, mapping threats using MITRE ATT&CK, and designing mitigation strategies aligned with the NIST Cybersecurity Framework.

## 🔹 Tasks Performed
- Designed segmented on-prem/cloud architecture  
- Identified assets, threats, and vulnerabilities  
- Performed risk analysis (likelihood, impact, severity)  
- Created a risk matrix and mitigation plan  
- Mapped threats to MITRE ATT&CK techniques  
- Developed an Incident Response plan (NIST 800-61 style)  

## 🔹 Tools & Frameworks
- NIST CSF  
- MITRE ATT&CK  
- Risk Matrix modeling  
- Network architecture diagrams  

## 🔹 Deliverables
- Risk assessment report (PDF)  
- Network architecture diagram  
- IR plan (Incident Response)  
- MITRE ATT&CK threat mapping  
- Implementation recommendations
